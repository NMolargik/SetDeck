## Description — 1617/4000
```
1週間を計画。すべてのセットを記録。成長を確認。
SetDeck は、トレーニーの実際のやり方に合わせて作られた筋力トレーニング記録アプリです。曜日ごとのルーティン、その中の種目、種目ごとのセットで構成されます。
データは iCloud でプライベートに同期され、Apple Watch はラックのそばですぐに使えます。

1週間を計画
• 日曜日から土曜日まで、曜日ごとにルーティンを用意し、種目カードのデッキとして表示
• 筋肉グループごとの色とアイコンが付いた、見やすい種目カード
• 4種類のセット: レップ、AMAP(できるだけ多く)、時間指定、フリーフォーム
• 種目をウォームアップに設定、並べ替え、重量・レップ数・時間の目標を設定
• 対応デバイスでは、筋肉グループをデバイス上で提案

ワンタップで記録
• 進めながらセットを完了にして、RPE で強度を評価
• 完了したセットはすべて履歴に保存
• ポンドとキログラムを切り替え

効果を確認
• トレーニングボリュームの推移を、30日、90日、全期間のビューで表示
• 今週鍛えた部位がわかる、前面と背面の筋肉ヒートマップ
• 筋肉の分布、バランス分析、強度(RPE)のグラフ
• 推定1RM つきの自己ベストと、種目ごとの進捗
• 継続、ボリューム、ルーティン、バラエティ、筋力にわたる19個の実績を、紙吹雪でお祝い

ヘルスケア、水分、エネルギー
• 筋力トレーニングのワークアウトをヘルスケアに記録
• ロック画面と Dynamic Island のライブアクティビティでワークアウト時間を表示
• 水分とカロリーを記録し、水分補給とエネルギーのグラフを確認
• ホーム画面用の水分・エネルギーウィジェット
• ワークアウトの開始と停止ができるコントロールセンターのコントロール
• 終了したワークアウトのサマリーを共有

水分補給リマインダー(新機能)
• 自分でオンにするオプションのリマインダー(初期設定ではオフ)
• 有効な時間帯、通知の頻度、毎日の目標を選択
• 目標に達すると、その日のリマインダーは停止
• 通知から直接「1杯を記録」をタップ

iPHONE DUO に対応(新機能)
• 展開すると、ルーティンのデッキが1週間の概要の横に並びます
• 統計は2カラムのダッシュボードに
• 設定はリストと詳細ペインに分割
• 標準の iPhone や iPad でも、これまでどおり快適に使えます

新しくなったルーティンエディタ(新機能)
• 1日の内容をひと目で確認
• 筋肉グループの色とアイコンが付いた、情報豊富な種目カード
• 各行を開かなくても、セットの種類と目標が読み取れます
• 追加、並べ替え、削除のわかりやすい操作

APPLE WATCH
• 手首で今日のルーティンを確認し、セットを記録
• セット間のガイド付きレストタイマー
• ワークアウトの開始と停止を Apple Watch から
• 今日のワークアウトのコンプリケーション
• ダブルタップまたはアクションボタンで次のセットを記録

SIRI、ショートカット、SPOTLIGHT
• 「今日のワークアウトは?」など、曜日を指定して質問
• ワークアウトの開始と停止、状況の確認、水分やカロリーの追加
• 種目を Spotlight で検索

プライバシー重視の設計
• ルーティンと履歴は、あなたのプライベートな iCloud に保存
• ヘルスデータは、許可した場合にのみ読み書き
• 分析やトラッキングは一切なし

対応言語: 英語、スペイン語、フランス語(カナダ)、日本語。
```
